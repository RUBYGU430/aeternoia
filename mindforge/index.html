구글 Gemini API Key를 연동하면, 주입하신 텍스트를 고도화된 프롬프트 컨텍스트로 구성하여 **실제 동작하는 완전한 전문 RAG 챗봇**을 사용할 수 있습니다.

API Key는 브라우저 내부(localStorage)에만 안전하게 저장되며, 어떤 서버로도 전송되지 않고 구글 API로만 직접 통신합니다.
Gemini 2.0 Thinking 모델은 답변 도출 전에 내부적인 단계별 추론 과정(Chain of Thought)을 명시적으로 기록하여, 주입된 데이터 기반의 정밀도를 대폭 끌어올립니다.
🔑 API Key 발급 방법
  1. Google AI Studio에 구글 계정으로 로그인합니다.
  2. 좌측 상단의 "Get API key"를 클릭합니다.
  3. 새로운 키를 생성하여 복사한 후 여기에 붙여넣습니다.
